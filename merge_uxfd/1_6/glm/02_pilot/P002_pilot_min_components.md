## 背景

### 为什么要确定最小组件依赖

WP0 的目标是"跑通 1 epoch"，但实际需要哪些组件才能跑通，需要提前确认：

1. **避免范围蔓延**: 只移植真正必需的组件，先跑通再优化
2. **评估工作量**: 不同组件的移植难度不同
3. **验证 Copy+Adapter**: 确认哪些组件需要 Adapter 层

### 典型组件类型

| 组件类型 | 文件示例 | 功能 |
|---------|---------|------|
| 2D 时频 | `Signal_processing_2D.py` | 1D → 2D 转换 |
| 融合 | `Fusion1D2D*.py` | 1D + 2D 特征融合 |
| 注意力 | `attention_*.py` | 注意力机制 |
| Fuzzy | `fuzzy_*.py` | 模糊逻辑 |
| Explainer | `explain_*.py` | 可解释性 |
