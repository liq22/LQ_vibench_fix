# F003: 三层对齐机制实现

**所属 Paper**: 📘 1D-2D_fusion_explainable
**分类**: 组件实现
**优先级**: P1
**依赖**: F001, F002

---

## 背景

### 现状描述
- 1D-2D 融合需要处理不同模态特征的对齐问题
- pilot 提到"三层对齐"：物理、语义、几何

### 为什么需要合并
- 确保 1D 和 2D 特征在同一语义空间
- 避免因维度/尺度不匹配导致的融合失败

### 当前问题
- 三层对齐的具体实现方式不明确
- 需要验证对齐是否必需

---

## 合并任务分解

### 子任务 1: 物理对齐
- [ ] 频率轴对齐：确保 1D 频域特征与 2D 频率轴对应
- [ ] 时间轴对齐：确保时间分辨率一致
- [ ] 实现对齐验证函数

**验收标准**: 对齐检查函数能检测不对齐情况

### 子任务 2: 语义对齐
- [ ] 特征空间对齐：使用 projection/normalization
- [ ] 跨模态特征对齐：确保 1D/2D 特征维度可融合
- [ ] 实现对齐层（如 Linear projection）

**验收标准**: 1D 和 2D 特征能拼接/相加

### 子任务 3: 几何对齐
- [ ] 维度匹配：处理 BLC vs BTFC 的维度差异
- [ ] 实现 reshape/expand 操作
- [ ] 编写对齐验证脚本

**验收标准**: 融合输入维度匹配

---

## 选项

### 选项 A: 实现完整三层对齐（推荐 ★）
- **描述**: 物理+语义+几何三层都实现
- **优点**: 对齐最完整
- **缺点**: 复杂度高

### 选项 B: 仅实现几何对齐
- **描述**: 只处理维度匹配
- **优点**: 简单快速
- **缺点**: 可能影响融合效果

### 选项 C: 先跳过，后续验证是否需要
- **描述**: 不做对齐，让融合模块自己处理
- **优点**: 最快
- **缺点**: 可能导致结果不可解释
