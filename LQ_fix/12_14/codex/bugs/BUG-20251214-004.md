# BUG-20251214-004（待确认）：ID_selector 多处裸 `except` 影响采样正确性

- 优先级：P0
- 模块：data_factory（samplers）
- 位置：`src/data_factory/samplers/del/ID_selector.py:106`
- 关联记录：`docs/LQ_fix/12_14/bugs/data_factory.md`

## 现象（代码证据）

至少 3 处裸 `except:`：
- `src/data_factory/samplers/del/ID_selector.py:106`
- `src/data_factory/samplers/del/ID_selector.py:129`
- `src/data_factory/samplers/del/ID_selector.py:140`

## 风险

- 采样过程的关键异常被吞掉，可能导致：
  - train/test 划分不正确
  - 某些数据被无声跳过（silent data loss）
  - 训练结果不稳定且难以复现

## 建议修复方案（最小变更）

- 用 `except Exception as e:` 替代裸 `except:`
- 在吞掉异常前记录上下文（至少：`id`、metadata 索引键、字段名）
- 对“不可恢复”的异常改为显式抛出（或计数后统一 fail-fast）

## 验收标准

- 不再存在裸 `except:`（上述 3 处）
- 发生异常时可定位（日志包含关键上下文）
