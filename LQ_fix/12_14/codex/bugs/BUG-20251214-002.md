# BUG-20251214-002（待确认）：`__del__` 裸 `except` 吞资源清理失败

- 优先级：P0
- 模块：data_factory
- 位置：`src/data_factory/H5DataDict.py:85`
- 关联记录：`docs/LQ_fix/12_14/bugs/data_factory.md`

## 现象（代码证据）

析构函数中捕获所有异常并静默忽略：
- `src/data_factory/H5DataDict.py:85`

## 风险

- 资源清理失败完全不可见，容易造成句柄泄漏
- 析构阶段吞掉异常会掩盖真实问题，且难以复现

## 建议修复方案（最小变更）

- 避免裸 `except:`，仅捕获 `Exception`
- 记录错误（注意：析构期间 logger 可能不可用，需用最稳妥的方式）
- 保持 `close()` 的幂等性（多次调用不报错）

## 验收标准

- 不再存在裸 `except:`（此处）
- 失败时有可观察日志/输出（至少 `sys.stderr`）
