# GLM（Granular Level Manual）

本目录用于存放 `docs/LQ_fix/12_14/PLAN.md` 的“可执行细化步骤”，目标是让任何人按步骤执行即可完成：
- 自动化扫描（可重复、低噪声）
- 手动审查（按模块）
- Bug 文档化（统一模板、索引、汇总）
- README/文档一致性检查（路径/链接/示例命令）

## 目录

- `01_preflight.md`：开始前检查（分支、工作区、目录）
- `02_auto_scan.md`：自动化扫描（rg 规则 + 记录方式）
- `03_manual_review.md`：手动审查（按模块的检查点清单）
- `04_triage_and_docs.md`：分级、建档、索引与汇总的具体操作
